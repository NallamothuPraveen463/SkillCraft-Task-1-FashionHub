# FashionHub - Responsive Fashion Shopping Website

## 📌 Project Overview

FashionHub is a responsive fashion shopping website developed as part of my Software Development Internship at SkillCraft Technology.

The project is designed to provide users with a modern and user-friendly online shopping experience with fashion categories, trending products, product prices, and shopping cart functionality.

## 🚀 Features

- Responsive fashion shopping interface
- Modern navigation bar
- Home, Men, Women, Beauty and Contact sections
- Fashion sale hero section
- Trending products section
- Product images and pricing
- Add to Cart functionality
- Shopping cart interaction
- Search products option
- Wishlist and profile options
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the FashionHub shopping website.
